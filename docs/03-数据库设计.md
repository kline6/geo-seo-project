# 03 - 数据库设计

## 数据库选择
SQLite（通过 better-sqlite3 npm 包）

## 存储位置
`{userData}/geo-seo-desktop/data.db`

## 表结构

### articles（文章）
```sql
CREATE TABLE IF NOT EXISTS articles (
  id            TEXT PRIMARY KEY,        -- UUID
  title         TEXT NOT NULL,
  slug          TEXT UNIQUE NOT NULL,     -- URL 友好标识
  file_path     TEXT,                     -- 本地 MD 文件路径
  content_md    TEXT NOT NULL DEFAULT '',
  language      TEXT NOT NULL DEFAULT 'zh-CN',
  author        TEXT NOT NULL DEFAULT '',
  status        TEXT NOT NULL DEFAULT 'draft',  -- draft/review/published
  current_score REAL DEFAULT NULL,        -- 最新审计分数
  tags          TEXT DEFAULT '[]',        -- JSON 数组
  meta_title    TEXT DEFAULT '',
  meta_desc     TEXT DEFAULT '',
  meta_keywords TEXT DEFAULT '[]',        -- JSON 数组
  created_at    TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at    TEXT NOT NULL DEFAULT (datetime('now'))
);
```

### audits（审计记录）
```sql
CREATE TABLE IF NOT EXISTS audits (
  id                TEXT PRIMARY KEY,     -- UUID
  article_id        TEXT NOT NULL,
  model_used        TEXT DEFAULT 'rule-based',  -- rule-based / gpt-4 / etc
  score             REAL NOT NULL,
  dimension_scores  TEXT NOT NULL,         -- JSON: {"citation_density":85,...}
  issues            TEXT NOT NULL,         -- JSON: [{id,severity,title,evidence,fix}]
  suggestions       TEXT DEFAULT '[]',     -- JSON: rewrite hints
  suggested_meta    TEXT DEFAULT '{}',     -- JSON: {title,description,keywords}
  content_snapshot  TEXT DEFAULT '',        -- 审计时的内容快照
  created_at        TEXT NOT NULL DEFAULT (datetime('now')),
  FOREIGN KEY (article_id) REFERENCES articles(id) ON DELETE CASCADE
);
```

### audit_diffs（优化对比）
```sql
CREATE TABLE IF NOT EXISTS audit_diffs (
  id                TEXT PRIMARY KEY,
  article_id        TEXT NOT NULL,
  before_audit_id   TEXT NOT NULL,
  after_audit_id    TEXT NOT NULL,
  delta_score       REAL NOT NULL,
  resolved_issues   TEXT DEFAULT '[]',     -- JSON: 已修复的 issue id 列表
  new_issues        TEXT DEFAULT '[]',     -- JSON: 新出现的 issue id 列表
  created_at        TEXT NOT NULL DEFAULT (datetime('now')),
  FOREIGN KEY (article_id) REFERENCES articles(id) ON DELETE CASCADE,
  FOREIGN KEY (before_audit_id) REFERENCES audits(id),
  FOREIGN KEY (after_audit_id) REFERENCES audits(id)
);
```

### knowledge_items（知识库条目）
```sql
CREATE TABLE IF NOT EXISTS knowledge_items (
  id          TEXT PRIMARY KEY,
  category    TEXT NOT NULL,            -- geo_basics/platform_strategy/tips/checklist
  title       TEXT NOT NULL,
  summary     TEXT DEFAULT '',
  body_md     TEXT NOT NULL DEFAULT '',
  tags        TEXT DEFAULT '[]',        -- JSON 数组
  source_url  TEXT DEFAULT '',
  version     INTEGER NOT NULL DEFAULT 1,
  created_at  TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at  TEXT NOT NULL DEFAULT (datetime('now'))
);
```

## 索引
```sql
CREATE INDEX IF NOT EXISTS idx_articles_status ON articles(status);
CREATE INDEX IF NOT EXISTS idx_articles_score ON articles(current_score);
CREATE INDEX IF NOT EXISTS idx_audits_article ON audits(article_id);
CREATE INDEX IF NOT EXISTS idx_audits_created ON audits(created_at);
CREATE INDEX IF NOT EXISTS idx_knowledge_category ON knowledge_items(category);
```

## 数据备份
- 数据库文件为单个 `.db` 文件，可直接复制备份
