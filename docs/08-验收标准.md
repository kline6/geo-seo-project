# 08 - 验收标准

## 功能验收

### F1. 内容创建闭环
- [ ] 可从空白页创建新文章
- [ ] 可选择模板一键生成文章骨架
- [ ] 可编辑 Markdown 内容
- [ ] 可编辑 frontmatter（title/description/keywords/author）
- [ ] 可保存到本地数据库和文件

### F2. GEO 审计闭环
- [ ] 编辑器中点击"审计"可触发 Python 审计
- [ ] 3 秒内返回审计结果
- [ ] 结果包含总分（0-100）
- [ ] 结果包含 6 个维度分
- [ ] 结果包含至少 3 条具体建议
- [ ] 每条建议含 severity + evidence + fix
- [ ] 审计结果自动保存到数据库

### F3. 优化与再审计
- [ ] 用户可按建议修改内容
- [ ] 修改后可再次审计
- [ ] 可查看两次审计的分数变化
- [ ] 可查看哪些 issue 已解决/新增

### F4. 报告导出
- [ ] 可导出单次审计为 JSON
- [ ] 可导出单次审计为 Markdown
- [ ] 可查看所有历史审计记录

### F5. 知识库
- [ ] 可搜索知识条目
- [ ] 可按分类浏览
- [ ] 审计建议可跳转到相关知识条目

### F6. SEO 元数据
- [ ] 可自动生成推荐 title/description
- [ ] 可检测长度和关键词
- [ ] 可一键回填 frontmatter

### F7. 工作台
- [ ] 显示文章总数、平均分
- [ ] 显示待优化文章列表
- [ ] 点击可跳转到对应文章

## 性能验收（本地）

| 指标 | 目标 |
|------|------|
| 编辑器首屏打开 | < 2 秒 |
| 自动保存响应 | < 500ms |
| 单篇 GEO 审计（本地规则） | < 3 秒 |
| 知识库搜索 | < 200ms |
| 报告导出 | < 2 秒 |

---

## 可靠性验收

| 场景 | 预期行为 |
|------|----------|
| 断网时编辑 | 正常编辑和保存，不报错 |
| 断网时审计 | 提示"需要联网"或降级为本地规则审计 |
| Python 进程崩溃 | 应用不崩溃，显示"审计服务异常"提示 |
| 数据库损坏 | 启动时自动备份旧文件，创建新数据库 |
| 大文件编辑（>10MB） | 编辑器不卡顿 |

---

## 体验验收

- 从打开应用到开始编辑 < 3 步
- 从编辑到看到审计结果 < 1 次点击
- 审计建议 70% 以上可直接复制使用
- 新手 30 分钟内可完成一次完整闭环
