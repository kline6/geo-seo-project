# GEO-SEO Desktop v2 — 完整重新构思

> 基于 AstroPaper + GEO AI Agent + Awesome GEO + GetCito 四大开源项目的核心理念重新设计
> 用户：ISO 9001 认证从业者（偏中国市场）

---

## 一、四大开源项目各自贡献了什么

### AstroPaper 贡献
- **内容系统**：类型安全的 Markdown/MDX frontmatter schema（author, pubDatetime, tags, ogImage, canonicalURL, description）
- **SEO 基建**：动态 OG 图片生成（Satori）、canonical URL、sitemap、RSS feed
- **用户体验**：亮/暗模式、响应式、Pagefind 静态搜索、分页、草稿系统、归档页
- **设计语言**：极简干净排版、可折叠目录、标签归档体系

### GEO AI Agent 贡献
- **多 Agent 协作审计**：6 个专门化 Agent（Title Scraper → Query Fanout → Main Query Extractor → AI Overview Retriever → Fanout Summarizer → Content Optimizer）
- **对比分析方法论**：将自身内容摘要与 Google AI Overview 对比，找差距
- **可执行建议生成**：基于对比结果输出 action items
- **SERP 数据获取**：通过 Bright Data 抓取真实 Google AI Overview 数据

### Awesome GEO 贡献
- **知识库内容源**：200+ 资源链接（平台策略、案例研究、工具清单、研究论文）
- **平台分类体系**：Google AI Overviews / ChatGPT Search / Perplexity / Claude / Gemini 各自的优化策略
- **行业基准**：工具对比、案例数据（2300% 流量增长等）
- **持续更新框架**：贡献指南和分类结构可直接复用

### GetCito 贡献
- **多引擎监控**：ChatGPT / Perplexity / Google AI Overview / Gemini 同时追踪
- **品牌提及分析**：品牌在 AI 回答中的出现频率、情感分析、引用来源
- **竞争分析**：竞争对手提及对比、Share of Voice（SOV）计算
- **Citation 追踪**：记录 AI 引用了哪些 URL、引用了什么内容
- **Dashboard 体系**：MetricCard / TrendCharts / Leaderboard / QueriesOverview / Recommendations
- **查询管理**：用户自定义查询列表，批量发送到多个 AI 引擎

## 四、新增模块详细设计

### 4.1 OG 图片生成（来自 AstroPaper）

技术方案：
- 使用 Satori（JS 版）在 Node 主进程中生成
- 输入：文章 title + description + author + 日期
- 输出：1200×630 PNG 图片
- 缓存：生成后保存到 `{userData}/data/og-images/{article-id}.png`
- 触发：文章保存时自动生成，也可手动重新生成

```
输入: { title, description, author, date }
     ↓
Satori JSX 模板（极简风格，白底黑字，带品牌标识）
     ↓
sharp 转 PNG
     ↓
保存到本地 + 返回 base64 给前端预览
```

### 4.2 多 Agent 审计（来自 GEO AI Agent）

v2 审计流程：
1. **规则层**（当前已有）→ 6 维度评分，纯本地，秒级
2. **对比分析层**（新增，可选联网）：
   - 从文章提取核心查询
   - 生成查询扇出（5-10 个相关查询）
   - 获取 Google AI Overview（需 API Key）
   - 生成自身内容摘要
   - 对比摘要 vs AI Overview → 差距分析
3. **多引擎验证层**（新增，可选联网）：
   - 将查询发送到 ChatGPT / Perplexity
   - 检查品牌/内容是否出现在 AI 回答中
   - 记录引用来源

关键：联网功能标记为"增强"，断网时规则层仍完整可用。

### 4.3 品牌监控（来自 GetCito）

数据模型：
```
brand_config: {
  id, brand_name, domain, keywords[], competitors[], created_at
}

brand_mentions: {
  id, brand_config_id, engine (chatgpt|perplexity|google_ai),
  query, mention_text, sentiment (positive|neutral|negative),
  citation_url, citation_domain, created_at
}

competitor_mentions: {
  id, brand_config_id, competitor_name, engine,
  query, mention_count, created_at
}
```

### 4.4 查询管理（来自 GetCito）

```
query_results: {

```

### 4.5 完整知识库（来自 Awesome GEO）

知识库 v2 内容量：

- 增强技巧：10 条（定义段、引用密度、FAQ、表格、列表等）
- 检查清单：5 条

- 案例研究：8 条（来自 Awesome GEO Case Studies）
- **合计：约 63 条知识条目**

## 九、验收标准 v2

### 功能验收
1. 可完成"新建 → 审计 → 优化 → 再审计"闭环
2. 优化建议至少 70% 可直接操作
3. 审计结果可导出 JSON/MD
4. OG 图片自动生成并可预览
5. 知识库可搜索、可从审计建议跳转
6. 品牌在 AI 引擎中的提及可追踪
7. 竞争对手 SOV 可对比

### 性能验收
- 编辑器首屏 < 2s
- 规则层审计 < 3s
- OG 图片生成 < 2s
- 知识库搜索 < 200ms
- 多引擎查询 < 30s（取决于 API）

### 可靠性验收
- 断网时编辑、保存、规则审计、知识库均可用
- AI API 异常时提示降级，不崩溃
- 数据库损坏时自动重建

### 一句话验收
当用户在离线时完成内容撰写和规则层审计，在联网时可选择性使用 AI 引擎查询验证，
获得至少 5 条可执行建议，看到品牌在 AI 搜索中的可见度，
并能在 30 分钟内完成一次完整闭环，本阶段目标达成。
