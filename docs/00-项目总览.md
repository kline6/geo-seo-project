# 00 - 项目总览

## 项目名称
GEO-SEO Desktop App — ISO 9001 内容优化桌面工具

## 一句话定义
本地桌面应用，帮助 ISO 9001 认证从业者创建"AI 更愿意引用"的内容，完成 GEO 审计 → 优化 → 再审计闭环。

## 核心价值
- 把 GEO 方法论变成可执行步骤
- 一次撰写，多维检查（GEO + SEO）
- 本地形成内容资产库与优化历史

## 技术栈
- 桌面框架：Electron
- 前端：React + TypeScript + Tailwind CSS
- 后端：Node.js（Electron 主进程）
- 审计引擎：Python（本地子进程调用）
- 数据库：SQLite（本地存储）
- 编辑器：CodeMirror / Monaco（MDX 编辑）

## 目标用户
ISO 9001 认证从业者（偏中国市场），质量管理/咨询人员

## 实施阶段
| 阶段 | 名称 | 核心交付 |
|------|------|----------|
| Phase 0 | MVP | 编辑器 + 模板 + 单篇 GEO 审计 + 报告页面 |
| Phase 1 | 效率 | 批量审计、优化前后对比、建议闭环统计 |
| Phase 2 | 增强 | 平台策略适配、本地语义检索、自定义权重 |
| Phase 3 | 资产化 | 知识图谱、内容看板、长期优化曲线 |
