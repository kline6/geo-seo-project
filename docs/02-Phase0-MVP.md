# 02 - Phase 0 MVP 实施计划

## MVP 目标
完成"新建 → 审计 → 优化 → 再审计"闭环，离线可编辑，联网可审计。

## 实施步骤（按顺序）

### Step 1: 桌面框架初始化
**任务**
- 初始化 Electron + React + TypeScript 项目
- 配置 Tailwind CSS
- 配置 Electron Builder 基础
- 实现主进程 ↔ 渲染进程 IPC 基础通信

**交付物**
- 可运行的 Electron 空壳应用
- 窗口标题、菜单栏基础

**验收**
- `npm run dev` 启动后弹出桌面窗口
- 可看到 React 欢迎页面

---

### Step 2: 本地数据库与文件存储
**任务**
- 集成 better-sqlite3
- 创建 articles / audits 表
- 实现文章 CRUD 仓库层
- 实现本地文件管理（MD/MDX 读写）

**交付物**
- SQLite 数据库自动初始化
- 文章增删改查 IPC 接口

**验收**
- 通过 IPC 可创建、查询、更新、删除文章记录
- 数据库文件在用户目录下可找到

---

### Step 3: 内容编辑器
**任务**
- 集成 CodeMirror 6（Markdown 模式）
- 实现 GEO 模板一键插入
- 实现 frontmatter 编辑面板
- 实现实时字数统计、阅读时长

**交付物**
- Markdown 编辑器页面
- 模板选择下拉菜单
- 元数据面板

**验收**
- 可新建文章并编辑
- 可插入模板生成文章骨架
- 可编辑 title/description/keywords 等 frontmatter

---

### Step 4: Python GEO 审计引擎
**任务**
- 搭建 Python 项目结构
- 实现 6 个评分维度（规则层，不依赖 AI）
- 实现建议生成器（基于规则）
- 实现 stdio 通信协议

**评分维度实现（规则层）**
1. 引用密度：检测引用标记、数据来源标注
2. 命题清晰度：首段是否有明确定义句
3. 结构可解析性：H2/H3 层级、列表、表格使用
4. 权威信号：标准编号、机构名称、数据年份
5. 事实可核验性：数字、百分比、日期引用
6. 平台适配度：FAQ 结构、列表密度、段落长度

**交付物**
- Python 可独立运行的审计脚本
- 输入 Markdown → 输出 JSON 评分报告

**验收**
- 命令行 `python audit.py --file test.md` 可输出 JSON
- 6 个维度均有分数和具体 issue

---

### Step 5: 审计界面与结果展示
**任务**
- 实现审计请求 IPC（Node → Python）
- 实现审计结果展示页面（总分、维度雷达图、问题列表）
- 实现建议卡片（每条含 severity + evidence + fix）
- 审计结果落库

**交付物**
- GEO 审计页面
- 雷达图组件（Recharts）
- 问题列表组件

**验收**
- 编辑器中点击"开始审计"后 3 秒内显示结果
- 结果包含总分、6 个维度分、至少 3 条具体建议
- 审计记录可查

---

### Step 6: SEO 元数据自动推荐
**任务**
- 基于文章内容自动生成推荐 title/description
- 检测长度、关键词覆盖
- 一键回填 frontmatter

**交付物**
- SEO 推荐面板组件

**验收**
- 编辑器右侧显示 SEO 推荐
- 可一键应用推荐值

---

### Step 7: 报告与历史页面
**任务**
- 实现历史审计记录列表
- 实现单篇审计历史时间线
- 实现导出功能（Markdown / JSON）

**交付物**
- 报告页面
- 导出功能

**验收**
- 可查看所有历史审计记录
- 可导出单次审计报告为 JSON/MD

---

### Step 8: 工作台仪表盘
**任务**
- 显示文章总数、平均分、待优化数量
- 显示近 7 天审计趋势
- 显示待优化文章列表

**交付物**
- Dashboard 页面

**验收**
- 首页显示关键指标
- 点击文章可跳转编辑器

---
