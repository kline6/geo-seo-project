## 通信方式
- React UI ↔ Node 主进程：Electron IPC（ipcRenderer / ipcMain）
- Node 主进程 ↔ Python 审计引擎：HTTP（localhost:PORT）或 stdio 管道
- 推荐 stdio 管道：启动开销小，无需额外端口管理

## 技术选型理由

| 选择 | 理由 |
|------|------|
| Electron | 跨平台桌面打包，Node 生态丰富，React 可直接复用 |
| React + TS | 类型安全，组件化开发，生态成熟 |
| Tailwind CSS | 快速搭建 UI，响应式，与组件库兼容好 |
| SQLite | 本地轻量数据库，无需安装，文件级存储 |
| Python 审计引擎 | 文本分析生态丰富（jieba, spacy 等），独立可替换 |
| stdio 管道通信 | 比 HTTP 更轻量，无需端口管理，启动快 |
| Zustand | 轻量状态管理，比 Redux 简单，TS 支持好 |
| CodeMirror 6 | 轻量 Markdown 编辑器，可扩展，性能好 |

## 打包策略
- Electron Builder 打包前端 + Node 主进程
- Python 引擎：打包为独立可执行文件（PyInstaller）或随应用分发 Python 环境
- MVP 阶段：假设用户本地有 Python 3.10+，通过 PATH 调用
- 后期：PyInstaller 打包为单文件 exe，内嵌到 Electron 资源目录
