## Features by Module

### 1. 工作台 (Dashboard)
- Welcome message with user info
- Quick stats: keywords, articles, diagnoses, visibility
- Quick action buttons (4)
- Hot keywords ranking

### 2. AI 智能助手 (AI Assistant)
- Chat mode / Workflow mode toggle
- Conversation history sidebar
- 6 AI capabilities:
  - GEO品牌诊断
  - SEO技术检测
  - AI信任度评分
  - 关键词扩展
  - 文章生成
  - 品牌对比
- Quick start prompts
- Natural language input

### 3. AI 诊断 (Diagnosis)
- Create new diagnosis (brand analysis)
- Fields: brand name, domain, keywords, competitors, language
- Report list (past diagnoses)
- Analyzes brand visibility across AI platforms

### 4. 素材库 (Asset Library)
- Keywords management (card grid with metrics)
- Titles management
- Images management
- Knowledge base (enterprise knowledge table)

### 5. AI 写作 (AI Writing)
- Writing templates (prompt templates)
- Article categories
- Writing tasks (workbench)
  - Title (with AI suggestion)
  - Template selection
  - Requirements (2000 chars)
  - Writing style (professional/casual)
  - Real-time generation
- Article list (generated content)

### 6. 热文复制 (Hot Article Replication)
- Single article replication
  - Paste content or input URL
  - Model selection (GPT-5, GPT-4.1)
  - AI rewriting
- Batch replication

### 7. 发布 (Publishing)
- **网媒发布**: Online media outlets
- **自媒体发布**: Self-media platforms
- **个人平台**: Personal platforms
- **SEO 建站**: SEO website building
- **Social platforms**: Facebook, Twitter(X), TikTok
- **媒体发稿**: Authoritative media press releases
  - 55+ media outlets
  - Region filtering
  - DA scores and traffic data
  - AI-assisted content generation

### 8. 数据分析 (Analytics)
- Overview dashboard
- Reports (visibility trend, category distribution)
- Query tools
- Records/history

### 9. AI 工具 (AI Tools)
- Keyword index query
- AI keyword expansion
- Manual keyword expansion
- Bar chart comparison

### 10. SEO & GEO
- SEO keyword tracking
  - Add keyword + target URL
  - Track Google ranking
  - Track GEO visibility
  - CPC and competition data
- SEO Audit
- Backlink analysis
- SEO reports

### 11. 信任度评分 (Trust Score)
- Content trust evaluation
- AI citation probability

### 12. 个人中心 (Profile)
- User settings
- Account management

### 13. 系统管理 (Admin)
- System configuration
- User management
