## 核心功能

### 1. 编辑器
- CodeMirror 6，Markdown 语法高亮
- 快捷键：Ctrl+B 粗体、Ctrl+I 斜体、Ctrl+S 保存
- 自动保存（防抖 3 秒）

### 2. 模板系统
预置模板（存储在 `python-engine/templates/`）：
- ISO 9001 文章通用模板
- 认证费用对比模板
- 行业实施指南模板
- FAQ 问答模板

模板插入后自动生成：
- frontmatter（title/description/date/author/tags）
- 结构化段落（定义段 → 核心要点 → 数据表格 → FAQ）

### 3. GEO 实时预检（轻量版）
不调用 Python，纯前端规则检查：
- 检测是否有 `>` 引言定义段
- 检测是否有表格 `|`
- 检测是否有 FAQ 关键词
- 检测段落长度（超过 150 字标黄）
- 检测标题层级（H2/H3 使用）

### 4. 元数据面板
- 显示和编辑 frontmatter 字段
- SEO 推荐（从审计引擎获取或本地规则生成）
- 一键"应用推荐"回填
